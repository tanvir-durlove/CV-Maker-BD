# CV Maker - Resume Builder

A modern, native Android CV maker and resume builder app built with Jetpack Compose, Material 3, and Kotlin. Features interactive drag-and-drop section reordering, handcrafted professional templates, live vector PDF export and printing, and monetization integration.

Developed by **NextGen Tools** (`nextgentoolbd@gmail.com`).

---

## Features
- **Modern Jetpack Compose UI**: Built following Material Design 3 guidelines with smooth animations and edge-to-edge support.
- **Handcrafted Templates**:
  - **Aura**: Modern 2-column sidebar design.
  - **Clarity**: ATS-friendly clean layout.
  - **Tradition**: Formal classic biodata structure.
  - **Continental**: Europass-standard layout.
- **Drag-and-Drop / Interactive Section Reordering**: Easily reorder Personal details, Experience, Education, Skills, Projects, and Languages.
- **On-Device PDF Engine**: Fast, local vector PostScript A4 PDF generation with live visual preview, native print dialog, and system share sheet integration.
- **Privacy by Default**: All user CV data is stored 100% locally on the device with zero cloud dependency.
- **Monetization Ready**: Integrated test banner ads, in-feed sponsor promotions, and rewarded/interstitial video ad flows.

## Building the APK
To assemble a debug APK:
```bash
gradle :app:assembleDebug
```
The generated APK will be located at:
`app/build/outputs/apk/debug/app-debug.apk`

To assemble a release APK/AAB:
```bash
gradle :app:assembleRelease
```
